## 2. `src/visualizations.py`

Six functions, matching the assignment spec:

| Function | Returns | Purpose |
|----------|---------|---------|
| `plot_histogram_with_distribution` | `plt.Figure` | Histogram + fitted-distribution overlay. Supports `normal`, `exponential`, `gamma`, `lognormal` (continuous, fit by MLE) **and** `poisson`, `binomial` (discrete, fit by matching the sample mean) |
| `create_correlation_heatmap` | `plt.Figure` | Correlation matrix heatmap for all numeric columns |
| `plot_boxplots_by_category` | `plt.Figure` | Boxplot of one numeric column, grouped by one categorical column |
| `create_interactive_scatter` | `plotly.graph_objects.Figure` | Interactive scatter plot, optionally colored by a category |
| `plot_qq_comparison` | `plt.Figure` | Q-Q plot against a chosen distribution, with a Shapiro-Wilk p-value annotation for the normal case |
| `dashboard_layout` | `dict` | Page config + sidebar option lists, so the dashboard's layout is unit-testable without a Streamlit runtime |

**Design choice - discrete distributions:** the course's learning objectives
call out normal, binomial, and Poisson distributions, but Week 2's
`fit_distribution` only tried continuous shapes (Normal, Exponential, Gamma,
Lognormal, Uniform). The dataset actually has a natural count variable -
`ca`, the number of major vessels (0-4) colored by fluoroscopy - so we added
Poisson and Binomial support specifically for columns like this. The
dashboard's Distributions tab offers Poisson/Binomial only when `ca` is
selected, alongside the continuous options.

**Design choice - no `plt.show()` inside the functions:** every Matplotlib
function returns the `Figure` object instead of calling `plt.show()`
directly. That lets the *same* function work in a notebook (`fig`), a script
(`fig.savefig(...)`), and the dashboard (`st.pyplot(fig)`), and makes the
functions straightforward to unit test.

## 3. `dashboard/app.py`

A three-tab Streamlit app, matching the spec's `Overview` / `Distributions` /
`Hypothesis Testing` structure:

- **Overview** - patient/diagnosis counts, a data preview, the Week 2 summary
  statistics table, the correlation heatmap, and a configurable interactive
  scatter plot (pick any X, Y, and color-by variable).
- **Distributions** - pick any numeric column and a distribution to fit;
  shows the histogram-with-overlay and a Q-Q plot side by side, plus a table
  ranking all fitted distributions by p-value. `ca` additionally offers the
  Poisson/Binomial fits.
- **Hypothesis Testing** - pick a t-test, ANOVA, or chi-square test, choose
  the variables interactively, and see the p-value, interpretation, and a
  supporting chart (boxplot or contingency table) update live.

Data loads once via `@st.cache_data` from `data/processed/cleaned_data.csv`
(the same file Week 1 produced), so the dashboard always reflects the cleaned
data without recomputing it on every interaction.

**Run it with:**
```bash
streamlit run dashboard/app.py
```

## 4. Unit Tests

- `tests/test_statistics.py` - 14 tests covering descriptive stats, normality
  tests, t-tests (one-sample and independent), ANOVA, chi-square, confidence
  intervals (traditional and bootstrap), and distribution fitting. Uses a
  fixed random seed for the Shapiro-Wilk normal-data test, since a true null
  hypothesis will "fail" roughly 1 in 20 times by chance with an arbitrary
  seed - that seed is documented in the test itself.
- `tests/test_visualizations.py` - 8 tests confirming every plotting function
  returns the right object type (`Figure` or Plotly `Figure`), that an
  invalid distribution name raises `ValueError`, and that `dashboard_layout`
  returns the keys the dashboard depends on. The Plotly test uses
  `pytest.importorskip("plotly")` so the suite still runs in environments
  where the (heavier, optional) Plotly dependency isn't installed.

Run both with:
```bash
pytest tests/ -v
```

*(These were written and manually verified against the real cleaned dataset
in this environment, but not run through `pytest` itself here - this sandbox
has no network access to install `pytest`, `streamlit`, or `plotly`. The
`requirements.txt` already lists all three, so `pip install -r
requirements.txt` followed by `pytest tests/ -v` will run the suite for
real.)*
